# Arbeitsbereich der Teilnehmenden

Dieses Verzeichnis ist für eigene Übungen, Änderungen und Beispiele während der Kubernetes-Schulung vorgesehen

Alle selbst erstellten Dateien und Anpassungen für die Übungen sollen innerhalb von `participant/` abgelegt werden

Die übrigen Verzeichnisse des Schulungsrepositories dienen als bereitgestellte Materialien und bleiben unverändert
